# AI Usage — How AI Was Used to Build Sweeft

This file documents the AI-assisted development workflow for Sweeft, as
required for the **Best AI-Native Build** consideration. It is updated as the
project progresses.

## Tooling

- **Coding agent**: OpenCode running in a terminal, used as the primary
  implementation assistant.
- **Models**: The agent was driven for planning, architecture review and
  implementation.

## Workflow

1. **Planning (19 Nov 2026)** — The implementation blueprint was reviewed
   against live QoreChain documentation (chain state, PQC precompiles,
   authenticators, the fest rules). Discrepancies between the blueprint and
   the live chain were resolved by querying the chain and docs directly.
2. **Scaffolding** — Repository structure, Django apps skeleton, Foundry
   workspace and environment configuration were generated by the agent and
   reviewed by the human.
3. **Smart contracts** — Contracts are written with the agent following the
   QoreChain `QDayVault` reference pattern; every function gains a Foundry
   test before the change is committed.
4. **Verification** — Testnet transactions are executed and verified on the
   explorer; the agent checks results against the chain rather than trusting
   local output.

## What the human contributes

- Product decisions (category, scope, what to cut).
- All wallet operations, key management and faucet claims.
- Review of every commit, contract deployment and testnet transaction.
- All live demonstrations and the final video.

## What AI generated

- Repository scaffolding, boilerplate, and configuration.
- Solidity contracts and Foundry tests (reviewed, line by line, before deploy).
- Django models, services, templates and JavaScript.
- Documentation drafts (this file, README, audit notes).

## Guardrails used

- AI never holds or checks keys: all signing happens in the owner's wallet
  (QoreX / Foundry scripts with throwaway testnet keys).
- AI-generated conclusions are never counted as trusted oracle attestations.
- The AI agent in the product spends only within an owner-signed, on-chain
  spending mandate; it cannot escalate its own limits.
